Files are SVG wrappers around real app JPEG captures (GitHub App tokens cannot upload private-repo issue attachments).

Stable URL pattern:

`https://cdn.jsdelivr.net/gh/ohthatgroup/Map@main/planit-ticket-shots/<n>.svg`
